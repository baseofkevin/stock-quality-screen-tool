# stock-quality-screen

独立的企业质量初筛工具：输入股票代码，输出**一个 HTML**。

它只回答两个问题：

1. 这家企业质量怎么样？
2. 当前价格能不能买？

不做行业故事、管理层评价、上下游分析，也不替代后续深度研究。全程规则计算，不调用大模型，不生成 JSON / Markdown。

---

## 快速开始

环境：

- Python 3.10+，**无第三方依赖**：只用标准库（`urllib` / `csv` / `zipfile` / `unittest`），
  不需要 pip install，也不需要虚拟环境
- Node.js 18+（`providers/westock_client.js` 跑在 node 上，是唯一的外部运行时依赖）
- 本机 WorkBuddy 已授权「腾讯自选股」连接器（`~/.workbuddy`）

```bash
python3 stock_report.py --stock-code 600519
```

输出：

```text
html-report/贵州茅台-企业质量初筛-20261108-213008.html
```

文件名包含生成日期和时分秒，例如 `20261108-213008`。默认输出到本项目目录下的 `html-report/`；该目录属于本地生成物，已在 `.gitignore` 中排除。

指定目录：

```bash
python3 stock_report.py --stock-code 301101 --out-dir /tmp/初筛
```

### CSV 批量模式

`--stock-code` 单股票模式保留不变；需要批量时用 `--csv`（旧名 `--csv-input` 仍可用，行为一致）：

```bash
python3 stock_report.py \
  --csv ../stock-kline-screen-tool/csv_output/选股_2026-11-06.csv
```

> **输入 CSV 只读**：批量模式不会改这个文件，一个字节都不动，指向只读的原始选股表
> 或别的工具刚产出的表都安全。批量**不产出任何 CSV，也不产出 Excel**——评分、链接
> 与二级行业等扩展列只体现在导航页（`html-report/<主名>.html`）里。

- 自动识别代码列，表头大小写不敏感，候选 10 个：`代码` / `股票代码` / `证券代码` / `股票` /
  `code` / `stock_code` / `stockcode` / `symbol` / `ts_code` / `sec_code`
  （见 `screen/batch.py:CODE_COLUMN_CANDIDATES`）；单元格支持 `600519`、`sh600519`、`600519.SH`。
- 用多线程并发生成，默认 4 个线程；可用 `--workers 8` 调整。
  注意：腾讯侧（5 次调用）有跨线程全局节流，`--workers` 主要并行的是东方财富取数
  和渲染，**不是线性加速**；盲目调大反而更容易撞限频。
- 每只股票的报告写入 `html-report/`，批量文件名带代码：
  `贵州茅台-sh600519-企业质量初筛-20261109-082004.html`。
- 批量结束后生成一份**真正可点击**的导航页，推荐用它查看（批量不写 CSV / Excel）：
  - `html-report/<输入 CSV 主名>.html`：浏览器导航页，每只股票两个按钮：
    「报告链接」和「东方财富网股票详情」，支持搜索。文件名跟输入 CSV 一致
    （`选股_2026-11-06.csv` → `html-report/选股_2026-11-06.html`）。
  - 表头共 10 列：`代码` / `名称` / `综合评分` / `二级行业` / `毛利率改善` /
    `池内换手分位` / `分位星级` / `总市值（亿）` / `报告` / `东方财富网`。
    后 5 列**原样取自输入 CSV 的同名列**，批量模式不重新计算、也不补空：
    上游没有这一列或这一行留空时，导航页显示 `—`，不会拿报告里另算的数去顶替。
    其中 `毛利率改善` 在 CSV 里是一整句（`否：20.84→18.83（环比未改善）；…`），
    导航页只显示开头的 `是` / `否`，细节点进报告第二节看。
- 导航页与报告目录、输入 CSV 用同一个主名，一眼能对上同一次输入
  （`选股_2026-11-06.csv` → `选股_2026-11-06.html`）。
- `综合评分` 列可能出现四种「非结论」值，含义不同，别混为一谈：

  | 值 | 含义 | 是否算失败 |
  |---|---|---|
  | `跳过：上市不足 3 年` | 年报 <3 个，硬门槛不处理（`config.MIN_ANNUAL_YEARS`），不生成 HTML | 否 |
  | `生成失败` | 取数或计算抛错，见终端 stderr | 是 |
  | `评分提取失败` | HTML 已生成，但从「四、综合评分」取结论失败 | 是 |
  | `代码无效` / `缺少股票代码` | 输入本身有问题 | 是 |

- 单只股票失败不影响其他股票：失败行写 `生成失败`，报告链接留空，命令最终退出码为 `1`；
  **跳过不算失败**，不会让退出码变成 1。
- **增量续跑**：再次执行同一条命令时，扫描 `--out-dir` 中已有的
  `*-{代码}-企业质量初筛-*.html`；能提取出结论的报告直接复用，只对缺失的股票重新抓数。
  续跑只依赖报告文件名里的代码，不依赖任何 CSV（批量本来也不写 CSV）。
  中断后直接重跑即可，不需要从头开始。
  `--force` 可忽略已有报告、强制全部重跑。
- **进度不丢**：每完成一只股票就原子落盘一份 HTML；按 `Ctrl-C` 会保留已完成部分、
  并按已完成部分生成导航页，下次运行继续补缺失的股票。
- **限频保护**：腾讯自选股调用有跨线程全局节流，默认每个请求间隔 1.6 秒
  （环境变量 `WESTOCK_GLOBAL_INTERVAL_MS` 可调）；限频 / 非 JSON / 超时错误默认重试
  2 次、每次等待 60 秒，可用 `--retries`、`--retry-wait` 调整；重试时终端会打印
  `[warn] ... 秒后重试`，不会无声卡住。可选数据（`data_profile` /
  `data_consensus` / `data_rating`）失败时只做一次短重试，随后记录为数据缺口，
  不会让每只股票多等两分钟。注意短重试的实际等待是 **3~8 秒**（3 秒基数加
  0~5 秒随机抖动，避免多个线程同时重试再次撞限频），不是固定 3 秒。
  东方财富侧另有跨线程节流，默认每个请求间隔 0.4 秒（`EASTMONEY_GLOBAL_INTERVAL_MS`）。
  若仍然频繁限频，
  可降低 `--workers` 或把 `WESTOCK_GLOBAL_INTERVAL_MS` 调大。
- **`--quiet`**：除了不打印摘要，也把上面的 `[warn] ... 秒后重试` 一起静音——
  失败仍会记进报告的数据缺口和导航页，只是不刷屏。

离线重放旧采集包（仍然是 HTML 输出，不生成 JSON）：

```bash
python3 stock_report.py --stock-code 600519 \
  --bundle tests/fixtures/mini_bundle.json \
  --out-dir /tmp/sq-test
```

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

## CLI 参数与退出码

### 参数

| 参数 | 默认值 | 作用 | 适用范围 |
|---|---|---|---|
| `--stock-code` | —（必填其一） | 股票代码：`600519` / `sh600519` / `600519.SH` | 单股票 |
| `--csv`（旧名 `--csv-input`） | —（必填其一） | 批量：读该 CSV 的代码列；**输入只读**，不写任何 CSV | 批量 |
| `--out-dir` | `html-report/`（项目内） | 报告输出目录 | 两者 |
| `--name` | 空 | 覆盖报告文件名里的公司名 | 仅单股票；批量传了会报错 |
| `--bundle` | 空 | 离线重放旧采集包，不发网络请求 | 仅单股票；批量传了会报错 |
| `--timeout` | `90` | 单次取数超时（秒） | 两者 |
| `--workers` | `4` | 批量并发线程数，必须 ≥1 | 仅批量 |
| `--retries` | `2` | 取数失败重试次数，不能 <0 | 两者 |
| `--retry-wait` | `60` | 重试前等待（秒），实际再加 0~5 秒随机抖动 | 两者 |
| `--force` | 关 | 忽略已有报告，全部重新生成 | **仅批量**（单股票本来每次都重新生成） |
| `--quiet` | 关 | 只输出错误，同时静音 `[warn] 重试` | 两者 |

`--stock-code` 与 `--csv` 互斥，必须给且只能给一个，缺失时 argparse 直接以退出码 2 结束。

### 退出码

| 码 | 含义 | 典型场景 |
|---|---|---|
| `0` | 成功 | 单股票报告已生成；批量所有行都有结论（`跳过：上市不足 3 年` 也算正常） |
| `1` | 批量有行失败 | 至少一行是 `生成失败` / `评分提取失败` / `代码无效` |
| `2` | 可预期的错误 | 参数冲突、CSV 读不了、找不到代码列、取数失败（`DataError`）、年报不足以外的校验失败 |
| `3` | 未预期的异常 | 单股票模式下抛了没被捕获的异常（程序 bug，看 traceback） |
| `130` | 被 `Ctrl-C` 中断 | 批量会先按已完成部分生成导航页再退出，重跑同一条命令即续跑 |

两条与退出码相关的约定：

- **跳过不算失败**：年报 <3 个的股票写 `跳过：上市不足 3 年`，退出码仍是 `0`，不生成 HTML；
- **批量里单只失败不影响其他股票**，失败行写 `生成失败`、链接列留空，最后统一返回 `1`。

## 输出结构

HTML 固定五节：

1. **一、生意本身**：行业、主营、产品/业务收入占比与毛利率、五年经营轨迹（含 有息负债 / 在建工程÷固资）、货款占用（占款比 + 合同负债）、近 5 年（20 个季度）单季毛利率/归母净利率曲线（附 ① 判定：毛利率 / 净利率 / 营业收入的同比与环比六个数字，并点名哪项、哪个口径没改善）、垄断性标注（人工维护，annotations/moat_annotations.yaml，按需标注非普查，当前覆盖自选股池 113 只）、存续安全四档、盈利结构三证据。
2. **二、经营质量与风险**：14 项高信号检查，分真伪 / 趋势 / 质量 / 安全四组，状态为 `命中 / 提示 / 通过 / 数据不足 / 不适用`；异常项逐条列出，通过项折叠在每组末尾，并给一句组合定性。
3. **三、企业估值与机构预期**：PE/PB/PS 历史分位及近 10 年（不足 10 年按全部可用历史）周频走势图、一句「估值位置」判断（七档：历史底部 / 下三分之一 / 中偏低 / 正中 / 中偏高 / 上三分之一 / 历史顶部）、机构对企业未来盈利的预期（预测表、目标价、评级、预期差提示）、用现金扣除与底线估值方式对企业进行估值。
4. **四、综合评分**：质量分 Q（含一行“第二节命中/提示几项、有没有触发降级”）、估值分 V、数据完整度、结论矩阵与一致性闸门。
5. **五、后续跟踪**：阈值化 watchlist。

不生成：

- `.json`
- `.md`
- 中间数据文件

计算都在内存里完成。`--bundle` 只是输入，不是输出。

## 评分口径

### 质量分 Q（0~100）

| 维度 | 权重 | 指标 |
|---|---:|---|
| 资本回报 | 30 | 5 年 ROIC 中位数 − WACC（14）、ROIC 高于 WACC 的年数（10）、ROE 中位数（6） |
| 现金创造力 | 25 | FCF 为正年数（6）、FCF/净利润（8）、CFO/净利润（7）、FCF/营收（4） |
| 资产负债表 | 20 | 净有息负债/EBIT、利息保障、商誉/净资产 |
| 成长与稳定 | 15 | 营收 CAGR、毛利率标准差 ×水平修正、ROE 标准差、股本稀释 |
| 会计质量 | 10 | 应计利润（近 3 年中位数）、扣非/归母 |

> **金融股不打分**：行业名含“银行/保险/证券”时，Q 与 V 直接标“金融股不适用”，
> 决策为“金融股不适用，不做初筛”（不给出可买，也不给出回避）。
> 银行没有毛利率、FCF、应收/存货这些科目，套用工业口径只会得到一堆 0 分。

0.9.0 的四处口径修正（权重表没变）：

1. 毛利率稳定性要乘水平修正 `clamp((毛利率中位数 − 15) / 10, 0, 1)`——5% 稳定毛利不算“稳定”；
2. 应计利润取近 3 年中位数，单年一次性项目不再决定这一格；
3. 现金组新增 FCF/营收（0~15% → 0~4），与盈利结构「现金创造」同口径；
4. 资本回报组新增 ROIC>WACC 年数，ROE 从 10 分降到 6 分（ROE 会被杠杆美化）。

### 估值分 V（0~100，机构口径）

| 维度 | 权重 | 指标 |
|---|---:|---|
| 机构目标价空间 | 40 | 目标价 / 现价 − 1，-30%~+30% 映射到 0~100 |
| 预测 PE 相对当前 PE | 20 | 当前 PE / 预测 PE − 1，-20%~+20% 映射到 0~100 |
| 预期未来净利增速 | 40 | 未来 1~3 年净利同比均值，-15%~+25% 映射到 0~100 |

```text
V = 机构对企业的估值 60 + 预期未来净利增速 40
机构对企业的估值 = 目标价空间 40 + 预测 PE 20
```

缺失项按可用权重归一；但至少要有一个机构估值指标和一个净利增速指标，V 才计算。
**无机构覆盖时 V 为空，Q 分仍正常展示，决策显示“数据不足，不下结论”。**

历史分位、那句「估值位置」、FCF 与现金底线只展示，不进入 V。

口径日某个指标为负（亏损）或缺失时，该指标本次判为「不可用」：分位表里显示 `—`，
**不退回历史最后一个正值**（那个值不属于口径日，会把几年前的 PE 当成今天的）。
亏损股的「预测 PE 相对当前 PE」因此不参与 V，报告里写「口径日 PE 为负，不参与」。

### 估值位置那句话（仅展示，0.9.3 起）

第三节走势图下面多一段话，把分位表读成一句判断：

```text
估值位置：PE 18%（下三分之一）、PB 6%（历史底部）、PS 17%（下三分之一）
　——　三个口径位置接近（跨度 12pp），中位落在下三分之一：估值偏便宜。
```

- **七档**：切点 10 / 30 / 45 / 55 / 70 / 90，结论词从「明显偏便宜」到「明显偏贵」；
- **定档取中位数**，不用平均（平均会被单个极端值拽走）；
- **跨度 > 25pp 才说分歧**，此时点名最低/最高的指标，并按 PE→利润端、PB→净资产端、
  PS→收入端 说明「哪一端更便宜」；
- 句中百分比与分位表「历史分位」列同源，不重算；不足两个指标则整段不显示；
- 分位越界或为 NaN 时按缺失处理（不夹取，否则 -5% 会读成「历史底部」）；
- **样本不足 1 年（<52 周）时不给档位**：只报分位，另写一句「分位样本仅 N 周，仅供参考」。
  10 周的序列也能凑出「中位落在历史顶部」，那反映的是上市时间短，不是估值位置。

切点表与边界见 `METHODOLOGY.md` §5；阈值在 `config.VAL_BANDS` / `VAL_SPREAD_TOL`。

### 现金扣除与底线估值（仅展示）

第三节末尾展示，不进入估值分 V，不改变决策矩阵。

```text
现金底仓   = 货币资金（不扣有息负债）
扣现金市值 = 总市值 − 货币资金
净利润总额 = 最近年报 net_profit_total（营业收入 × 净利率的近似值）
扣现金 PE  = 扣现金市值 ÷ 净利润总额
盈利收益率 = 净利润总额 ÷ 总市值 × 100%

底线价值(N) = 货币资金 + N × 净利润总额
每股底线(N) = 底线价值(N) ÷ 总股本
安全边际(N) = (底线价值(N) − 总市值) ÷ 底线价值(N) × 100%
```

`N` 取 `config.CASH_ANCHOR_YEARS = (3, 5, 10, 15, 20)`。年限是情景假设，不是目标价；
金融股不适用；净利润总额缺失或非正时，底线估值不计算。

安全边际的分母是**底线**，所以市值远高于底线时会算出 −488% 这种数。表格里同一格
还会给「市值 N 倍」（`cap_times = 总市值 ÷ 底线价值`），差几倍一眼能读出来。

### 数据完整度与可买条件

不再计算 0~100 的置信度。报告只展示：

- 第二节风险检查已知多少项；
- 第三节机构覆盖多少家；
- Q 分数据覆盖多少。

买入类结论必须满足：

```text
机构覆盖 ≥ 3 家
Q 数据覆盖 ≥ 80%
关键风险检查无“数据不足”
```

不满足时，买入类结论降为“观察，等待数据完整”，并写明缺失原因。

### 质量调整后的结论矩阵

Q 越高，要求的 V 越低；Q<45 时无论 V 多高都禁止买入。

> 下表的数字来自 `config.DECISION_MATRIX`：`score._decision()` 按它取结论，
> 报告第四节的「决策规则」说明文字也从同一张表生成。改门槛只改 config 一处，
> 代码与报告文字会一起变（`tests/test_config_contract.py` 守着这一点）。

| 质量档 | Q 分 | 买入所需最低 V | 结论 |
|---|---:|---:|---|
| 优秀/良好 | ≥75 | ≥65 | 推荐买入 |
| 中等偏上 | 65~75 | ≥70；V≥80 推荐 | 可买/推荐 |
| 一般 | 55~65 | ≥75 | 小仓买入 |
| 偏弱 | 45~55 | ≥80 | 小仓试错 |
| 差 | <45 | 不买 | 回避 |

低于买入门槛时：

| Q 分 | V 分 | 结论 |
|---:|---:|---|
| ≥75 | 50~65 | 好公司，等价格 |
| ≥75 | 35~50 | 好公司，但偏贵，等价格 |
| ≥75 | <35 | 好公司，但太贵 |
| 65~75 | 50~70 | 观察 |
| 65~75 | <50 | 回避 |
| 55~65 | 50~75 | 观察 |
| 55~65 | <50 | 回避 |
| 45~55 | 65~80 | 观察 |
| 45~55 | <65 | 回避 |
| <45 | 任意 | 回避 |

Q 分档：≥85 优秀、75~85 良好、65~75 中等偏上、55~65 中等、45~55 偏弱、<45 差。
V 分档：≥80 明显低估、65~80 低估、50~65 合理、35~50 偏高、<35 明显高估。
分档只是标签，不改变结论矩阵；矩阵只认 Q/V 的数值。

**一致性闸门（0.9.0）**：矩阵给出买入类结论后，还要过一遍第二节——

| 第二节状态 | 买入类结论 |
|---|---|
| 命中 0 项、提示 ≤1 项 | 不变 |
| 提示 ≥2 项，或命中 1 项 | 观察，第二节有信号 |
| 命中 ≥2 项，或现金流质量/现金短债比命中 | 回避 |

闸门只压买入方向，“太贵/回避”不因此更保守；它先于“数据不完整”生效（回避比观察更重）。
报告第四节 Q 卡片下会写一行“第二节命中几项、提示几项 → 有没有触发降级”。

机构预期直接决定 V 分；评级分布只展示，不参与打分。预期差提示仍保留在第三节机构预期块内。

## 重要边界

1. **机构预期不是事实**。目标价、预测净利会进入 V 分，但只作参考，不代表未来一定实现。
2. **覆盖机构少于 3 家**时，预测只作提示，买入类结论降为“观察”。
3. **WACC 固定 9%**，不是逐公司精确计算；只用于 ROIC−WACC 与盈利结构判断。
4. **金融股不打分、强周期股**需人工复核：识别到银行/保险/证券时 Q/V 标“不适用”；
   强周期股的 FCF、净有息负债口径仍会自动计算，但结论要人工判断周期位置。
5. **商誉字段缺失按 0 处理**，报告会标注“接口未返回，建议核对年报”。
6. 若最新报告期是季报，FCF 仍使用最近年报，避免“单季 OCF − 全年 capex”的错配。
   东财资本支出是年内累计值，只认 `12-31` 年报行；某年只有季报行时 FCF 记为未知，不用 Q1 累计值顶替。
7. **季度利润率曲线只展示近 5 年（20 个季度）**，单季、未年化；净利率为归母口径，不进入 Q/V。可用季度不足 20 个时展示全部，并在图下注明。
8. **估值曲线只展示近 10 年、周频**（数据不足 10 年时展示全部可用历史）；分位仍按全部可用历史计算，但历史分位不进入 V。PE 为负的期间断线，用灰色区间标注。
9. 东财估值序列对老股票通常从 2018 年开始，不保证覆盖上市以来全部历史。
10. **现金扣除块不扣有息负债**，直接使用货币资金；净利润总额是用“营业收入 × 净利率”近似，不是财报直接披露的原始字段。金融股不适用。该块只展示，不进入 V 分。
11. **V 分只使用机构预测**：目标价、预测 PE、未来净利增速。无机构覆盖时 V 为空，但 Q 分仍照常计算。
12. **不再使用置信度分数**。数据是否足够，直接展示为风险检查已知项数、机构覆盖数和 Q 数据覆盖；只影响买入类结论，不影响“回避/太贵”等负面结论。
13. **Q<45 是硬性禁止买入线**，V 再高也不改变；45~55 只允许明显低估时小仓试错。
14. **小基数保护（两道门槛，都是实测踩出来的）**：应收增速差在应收/营收 <0.5% 时跳过、
    <2% 时只提示（600519 应收仅 0.03 亿，2024 年票据从 0.05% 跳到 1.17% 就是 +2596%）；
    存货增速差在存货/营收 <1% 时跳过（300058 存货 0.13 亿，2024 年"存货 +113%"是噪音）。
    跳过的项判"数据不足"，不判通过。阈值见 `config.AR_BASE_RATIO_MIN / AR_MATERIAL_RATIO /
    INV_MATERIAL_RATIO`。
    **基数判定先于档位判定**：应收占营收 0.5%~2% 时，即使连续两年增速差 >15pct 也只提示
    （0.9.4 之前这条会命中，而命中 1 项就让买入类结论降"观察"）。
15. **全篇估值统一用「口径日收盘价」**（口径日 = 估值序列最后一个交易日）：
    分位表的“最新收盘”、走势图最后一个点、目标价空间、现金底线的市值都用同一个收盘价。
    代价是盘中运行时不是实时价，报告头会写「估值口径 2026-11-09 收盘 · 数据快照 2026-11-10」。
16. **口径日指标为负或缺失 = 该指标不可用，不回退**：PE/PB/PS 分位表中该行显示 `—`，
    不退回历史最后一个正值（600733 口径日 PE 为 −6.80，退回去会拿 2020-04-29 的 206.18
    当“最新”），也不算分位、不进 V。亏损股的「预测 PE 相对当前 PE」因此缺失，
    V 按剩余权重归一，文案写「口径日 PE 为负，不参与」。
17. **上市不足 3 年直接跳过，不出报告**：年报 <3 个（`config.MIN_ANNUAL_YEARS`）时不打分、
    不生成 HTML，批量里写「跳过：上市不足 3 年」，退出码仍为 0。
    这是硬门槛——2 个点的 σ、2 年 CAGR 用来定性比「失败」更危险。金融股同样适用，不做例外。
18. **`examples/` 里的样例是历史版本生成的**，版式与当前输出不同（见 `examples/README.md`）。
    要当前版式的样例，用 `--bundle tests/fixtures/mini_bundle.json` 现场跑一份；
    该目录只有说明文件入库，报告本身是本地生成物。
19. **批量模式不改输入 CSV，也不产出新的 CSV / Excel**（0.9.9 起只读输入，0.9.10 起
    移除 Excel 产物）：`--csv` 指向的表只读，所以指向只读表、别人正在用的表、
    原始选股表都是安全的。评分、链接与二级行业等扩展列只出现在导航页
    （`html-report/<主名>.html`）里——要看结果看这一个文件，不要指望输入表被回填。
