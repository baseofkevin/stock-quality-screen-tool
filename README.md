# stock-quality-screen

独立的企业质量初筛工具：输入股票代码，输出**一个 HTML**。

它只回答两个问题：

1. 这家企业质量怎么样？
2. 当前价格能不能买？

不做行业故事、管理层评价、上下游分析，也不替代后续深度研究。全程规则计算，不调用大模型，不生成 JSON / Markdown。

---

## 快速开始

环境：

- Python 3.10+
- Node.js 18+
- 本机 WorkBuddy 已授权「腾讯自选股」连接器（`~/.workbuddy`）

```bash
python3 stock_report.py --stock-code 600519
```

输出：

```text
html-report/贵州茅台-企业质量初筛-20261107.html
```

默认输出到本项目目录下的 `html-report/`；该目录属于本地生成物，已在 `.gitignore` 中排除。

指定目录：

```bash
python3 stock_report.py --stock-code 301101 --out-dir /tmp/初筛
```

离线重放旧采集包（仍然是 HTML 输出，不生成 JSON）：

```bash
python3 stock_report.py --stock-code 600519 \
  --bundle tests/fixtures/mini_bundle.json \
  --out-dir /tmp/sq-test
```

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

## 输出结构

HTML 固定五节：

1. **一、生意本身**：行业、主营、产品/业务收入占比与毛利率、五年经营轨迹、近 15 个季度单季毛利率/归母净利率曲线、护城河规则结论。
2. **二、经营质量与风险**：10 项高信号检查，状态为 `命中 / 通过 / 数据不足`。
3. **三、企业估值与机构预期**：PE/PB/PS 历史分位及近 15 个季度周频走势图、机构对企业未来盈利的预期（预测表、目标价、评级、预期差提示）、对企业进行 DCF 估值、用现金扣除与底线估值方式对企业进行估值。
4. **四、综合评分**：质量分 Q、估值分 V、数据完整度、结论矩阵。
5. **五、后续跟踪**：阈值化 watchlist。

不生成：

- `.json`
- `.md`
- 中间数据文件

计算都在内存里完成。`--bundle` 只是输入，不是输出。

## 只取 8 类数据

| # | 数据 | 来源 | 用途 |
|---|---|---|---|
| 1 | 名称、行业、主营 | `data_profile` | 第一节 |
| 2 | 现价、市值、PE/PB | `data_quote` | 估值 |
| 3 | 5~6 年年报 + 季度报告期 | `data_finance(fields=all,num=20)` | 质量、风险、估值、季度利润率 |
| 4 | 机构一致预期 | `data_consensus` | 未来盈利、目标价 |
| 5 | 机构评级 | `data_rating` | 覆盖机构、评级分布 |
| 6 | 产品/业务分部 | 东方财富 `RPT_F10_FN_MAINOP` | 收入占比、分产品毛利率 |
| 7 | PE/PB/PS 历史序列 | 东方财富 `RPT_VALUEANALYSIS_DET` | 分位、近 15 季度周频曲线 |
| 8 | 资本支出 | 东方财富 `RPT_F10_FINANCE_GCASHFLOW` | FCF |

默认不取：

- 同业公司；
- 新闻、公告、研报全文；
- 25 条旧排雷；
- 管理层、行业空间等定性数据；
- 一致预期之外的卖方预测。

## 评分口径

### 质量分 Q（0~100）

| 维度 | 权重 | 指标 |
|---|---:|---|
| 资本回报 | 30 | 5 年 ROIC 中位数 − WACC、ROE 中位数 |
| 现金创造力 | 25 | FCF 为正年数、FCF/净利润、CFO/净利润 |
| 资产负债表 | 20 | 净有息负债/EBIT、利息保障、商誉/净资产 |
| 成长与稳定 | 15 | 营收 CAGR、毛利率标准差、ROE 标准差、股本稀释 |
| 会计质量 | 10 | 应计利润、扣非/归母 |

### 估值分 V（0~100，机构口径）

| 维度 | 权重 | 指标 |
|---|---:|---|
| 机构目标价空间 | 40 | 目标价 / 现价 − 1，-30%~+30% 映射到 0~100 |
| 预测 PE 相对当前 PE | 20 | 当前 PE / 预测 PE − 1，-20%~+20% 映射到 0~100 |
| 预期未来净利增速 | 40 | 未来 1~3 年净利同比均值，-15%~+25% 映射到 0~100 |

```text
V = 机构对企业的估值 60 + 预期未来净利增速 40
机构对企业的估值 = 目标价空间 40 + 预测 PE 20
```

缺失项按可用权重归一；但至少要有一个机构估值指标和一个净利增速指标，V 才计算。
**无机构覆盖时 V 为空，Q 分仍正常展示，决策显示“数据不足，不下结论”。**

历史分位、FCF 收益率、DCF 折价和现金底线只展示，不进入 V。

### 现金扣除与底线估值（仅展示）

第三节末尾展示，不进入估值分 V，不改变决策矩阵。

```text
现金底仓   = 货币资金（不扣有息负债）
扣现金市值 = 总市值 − 货币资金
净利润总额 = 最近年报 net_profit_total（营业收入 × 净利率的近似值）
扣现金 PE  = 扣现金市值 ÷ 净利润总额
盈利收益率 = 净利润总额 ÷ 总市值 × 100%

底线价值(N) = 货币资金 + N × 净利润总额
每股底线(N) = 底线价值(N) ÷ 总股本
安全边际(N) = (底线价值(N) − 总市值) ÷ 底线价值(N) × 100%
```

`N` 取 `config.CASH_ANCHOR_YEARS = (3, 5, 10, 15, 20)`。年限是情景假设，不是目标价；
金融股不适用；净利润总额缺失或非正时，底线估值不计算。

### 数据完整度与可买条件

不再计算 0~100 的置信度。报告只展示：

- 第二节风险检查已知多少项；
- 第三节机构覆盖多少家；
- Q 分数据覆盖多少。

买入类结论必须满足：

```text
机构覆盖 ≥ 3 家
Q 数据覆盖 ≥ 80%
关键风险检查无“数据不足”
```

不满足时，买入类结论降为“观察，等待数据完整”，并写明缺失原因。

### 质量调整后的结论矩阵

Q 越高，要求的 V 越低；Q<45 时无论 V 多高都禁止买入。

| 质量档 | Q 分 | 买入所需最低 V | 结论 |
|---|---:|---:|---|
| 优秀/良好 | ≥75 | ≥65 | 推荐买入 |
| 中等偏上 | 65~75 | ≥70；V≥80 推荐 | 可买/推荐 |
| 一般 | 55~65 | ≥75 | 小仓买入 |
| 偏弱 | 45~55 | ≥80 | 小仓试错 |
| 差 | <45 | 不买 | 回避 |

低于买入门槛时：

| Q 分 | V 分 | 结论 |
|---:|---:|---|
| ≥75 | 50~65 | 好公司，等价格 |
| ≥75 | 35~50 | 好公司，但偏贵，等价格 |
| ≥75 | <35 | 好公司，但太贵 |
| 65~75 | 50~70 | 观察 |
| 65~75 | <50 | 回避 |
| 55~65 | 50~75 | 观察 |
| 55~65 | <50 | 回避 |
| 45~55 | 65~80 | 观察 |
| 45~55 | <65 | 回避 |
| <45 | 任意 | 回避 |

Q 分档：≥85 优秀、75~85 良好、65~75 中等偏上、55~65 中等、45~55 偏弱、<45 差。
V 分档：≥80 明显低估、65~80 低估、50~65 合理、35~50 偏高、<35 明显高估。

机构预期直接决定 V 分；评级分布只展示，不参与打分。预期差提示仍保留在第三节机构预期块内。

## 重要边界

1. **机构预期不是事实**。目标价、预测净利会进入 V 分，但只作参考，不代表未来一定实现。
2. **覆盖机构少于 3 家**时，预测只作提示，买入类结论降为“观察”。
3. **WACC 固定 9%**，不是逐公司精确计算；DCF 只作估值参考，不是目标价。
4. **金融股、强周期股**不适合直接套用 FCF/DCF；遇到时应人工复核。
5. **商誉字段缺失按 0 处理**，报告会标注“接口未返回，建议核对年报”。
6. 若最新报告期是季报，FCF 仍使用最近年报，避免“单季 OCF − 全年 capex”的错配。
7. **季度利润率曲线只展示近 15 个季度**，单季、未年化；净利率为归母口径，不进入 Q/V。
8. **估值曲线只展示近 15 个季度、周频**；分位仍按全部可用历史计算，但历史分位不进入 V。PE 为负的期间断线，用灰色区间标注。
9. 东财估值序列对老股票通常从 2018 年开始，不保证覆盖上市以来全部历史。
10. **现金扣除块不扣有息负债**，直接使用货币资金；净利润总额是用“营业收入 × 净利率”近似，不是财报直接披露的原始字段。金融股不适用。该块只展示，不进入 V 分。
11. **V 分只使用机构预测**：目标价、预测 PE、未来净利增速。无机构覆盖时 V 为空，但 Q 分仍照常计算。
12. **不再使用置信度分数**。数据是否足够，直接展示为风险检查已知项数、机构覆盖数和 Q 数据覆盖；只影响买入类结论，不影响“回避/太贵”等负面结论。
13. **Q<45 是硬性禁止买入线**，V 再高也不改变；45~55 只允许明显低估时小仓试错。
